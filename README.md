# Weeb Flashcards

Weeb Flashcards is a beginner-friendly desktop flashcard app made using Electron.js to help anime lovers and weebs memorize popular Japanese phrases! It features simple flip-card mechanics with Japanese text on the front and English meaning on the back.

---

##  Features

-  Popular Japanese phrases used by weebs
-  Flip-style flashcards (interactive)
-  Beginner-friendly source code
-  Electron-based desktop app (.exe)
-  Android version (.apk) in development
-  Simple, editable UI (HTML/CSS/JS)

---

##  Tech Stack

- Electron.js
- Node.js
- HTML, CSS, JavaScript

##  How to Run the App (Development)

1. Clone the repository:

```bash
git clone https://github.com/PROTOX-1/Weeb-Flashcards.git
cd weeb-flashcards
```

2. Install the dependencies:

```bash
npm install
```

3. Start the app:

```bash
npm start
```

---

##  How to Build a Windows `.exe`

If you want to build the app as a `.exe` for Windows:

```bash
npm run dist
```

This requires Electron Builder (`electron-builder`) to be added in your project.
